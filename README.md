# Sap City

- Live site: https://reservetempo.github.io/sap-city/

Plain HTML, CSS and JavaScript with no build step. GitHub Pages serves the `main` branch root, so anything pushed to `main` goes live within a minute or two.

## Run locally

Open `index.html` in a browser, or serve the folder over HTTP (needed once the site uses ES modules):

```sh
python -m http.server 8000
```

Then open http://localhost:8000/.
